
# Introdução ao Go

Go é uma linguagem de programação criada pelo Google.


Ela foi projetada para ser simples, rápida e eficiente.


## Características principais


- Compilada
- Concorrente
- Tipagem estática
- Alta performance


## Instalação


Para instalar o Go, acesse:


https://go.dev/d1/


Baixe a versão compativel com seu sistema operacional e siga o instalador.
